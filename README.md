# PRODIGY_ML_04
task4 in machine learning

## Objective

Develop a hand gesture recognition model capable of classifying different hand gestures using deep learning.

## Dataset

Rock Paper Scissors Dataset:
https://www.kaggle.com/datasets/drgfreeman/rockpaperscissors

## Technologies Used

- Python
- TensorFlow
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Workflow

- Load dataset
- Preprocess images
- Split into training and validation sets
- Build CNN model
- Train the model
- Evaluate accuracy
- Predict hand gestures

## Output

The trained CNN classifies images into:

- Rock
- Paper
- Scissors
